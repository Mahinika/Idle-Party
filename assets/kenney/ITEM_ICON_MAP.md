# Item icon map (Classic gear)

Inventory icons resolve via `KenneyAssets.equipmentIconFor`.

## Tiny Dungeon (bundled)

| Tile / asset | Use |
|--------------|-----|
| 101–102 | Shields (off-hand shield) |
| 103 | Dagger / fist |
| 104 / 106 | Sword |
| 117 | Mace (hammer) |
| 118 | Axe |
| 129–130 | Staff / wand |
| 131 | Polearm (spear) |
| 113–116, 125–128 | Consumables |
| extras/ring.png | Fallback rings (prefer `custom/icons/ring.png`) |
| extras/book.png | Fallback tome (prefer `custom/icons/tome.png`) |
| icons/bow.png | Bow / crossbow / gun / thrown (from Board Game Icons) |
| custom/icons/*.png | Helm, chest, cloak, boots, gloves, ring, shoulders, belt, neck, wrist, legs, trinket, tome |

## Gaps / future imports

Dedicated sprites for extra pet species (`ash_fox`, `gold_grub`, …) currently remap to nearest existing pet PNG.
