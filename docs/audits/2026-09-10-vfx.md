# VFX audit — all dungeon combat effects

**Date:** 2026-09-10  
**Auditor:** Cursor agent  
**Depth:** full (all dungeon visual layers)  
**Scope:** combat VFX only — spells, hits, floaters, auras, God Hand, stairs/GO, Full/Lite/Minimal  
**Playtest:** no (code + existing tests only)  
**Build / branch:** working tree ~1.12.117  

**Out of scope:** menu chrome, hub, paper-doll, SFX/audio, Kenney tile art.

**Legal:** no foreign art dumps; VFX is Canvas-painted from owned helpers (`AGENTS.md`).

---

## Executive summary

Idle Party dungeon VFX is a **sim → world lists → Canvas paint** pipeline. Combat resolves in `SpatialCombat`; identity comes from `SpellVfx` + `AbilityVfxSpec` + central id maps; drawing is almost entirely `_TileRoomPainter` in `spatial_dungeon_view.dart`.

| Area | Verdict |
|------|---------|
| Architecture | **OK** — single combat authority, clear spawn vs paint split |
| Progress chrome (GO, open door) | **OK** — always visible, even Minimal |
| God Hand on Lite | **OK** — smash rings exempt from `reducedVfx` |
| Lite VFX honesty | **P0 bug** — painter promises discs/auras; spawn path blocks them |
| Kit identity coverage | **Mixed** — 35% have `AbilityVfxSpec`; id-map covers many more |
| Nature heal visuals | **P1 wrong** — green heals read as poison bursts |
| Enemy VFX | **Thin** — hit flash + generic red burst + text floaters |

**Biggest gap:** Lite VFX does not spawn ground discs (Consecration, Bladestorm, etc.) despite Settings, What’s New 1.12.5, and `VfxQuality` flags saying it should.

**Biggest strength:** layered fallback (def → id-map → AoE shape → keywords → hero default) keeps most spells themed without 271 explicit specs; spot tests catch false-positives (Cheap Shot ≠ arrow).

## Part 1 — What VFX means here

**VFX** = *visual effects*: anything drawn on the dungeon canvas during combat that is not the tile map, sprites, or HUD chrome.

Not included: mute/SFX (`game_audio.dart`), loading splash, menu sheets.

### Data flow

```
ClassAbilityDef (vfx / boltStyle)
        ↓
AbilityEffectRunner + SpellVfx
        ↓
SpatialCombat._spawnBurst / _spawnGroundFx / _spawnFloater / _spellBolt
        ↓
SpatialWorld lists + actor timers (hitFlash, castFlash, buff timers)
        ↓
_TileRoomPainter.paint (spatial_dungeon_view.dart)
```

### Source-of-truth files

| Layer | Path |
|-------|------|
| Per-ability overrides | `lib/models/ability_vfx.dart` (`AbilityVfxSpec`) |
| Kit definitions | `lib/models/class_ability.dart` |
| Bolt / burst / ground maps | `lib/spatial/spell_vfx.dart` |
| Ability cast → VFX spawn | `lib/spatial/ability_effects.dart` |
| World lists, caps, helpers | `lib/spatial/spatial_combat.dart` |
| Quality settings | `lib/models/vfx_quality.dart` |
| Canvas paint | `lib/ui/spatial_dungeon_view.dart` |
| Offline (forces Minimal) | `lib/core/offline_sim.dart` |
| Camera punch | `lib/core/game_director.dart` (`pulseCombatShake`) |
| Tests | `test/spell_vfx_test.dart` |

## Part 2 — VFX layer inventory

### 2.1 Bursts (`SpatialBurst` + `SpatialBurstKind`)

**Cap:** 22 (`_maxBursts`)

| Kind | Visual | Typical use |
|------|--------|-------------|
| `blast` | Soft filled disc | Default impact |
| `slash` | Weapon swing arc | Bladestorm, Whirlwind, melee |
| `ring` | Expanding hollow ring | Nova pop, God Hand |
| `cone` | Forward wedge | Shockwave |
| `spark` | Tiny ticks | PoM bounce, Living Bomb fuse |
| `beam` | Line / zigzag | Chain Lightning, Penance, Holy Shock |
| `rain` | Falling streaks | Blizzard, Hurricane, Volley, Healing Rain |
| `shards` | Ice crystals | Howling Blast, Frost Nova, Ice Lance |
| `flame` | Flame petals | Fireball, Immolate, Lava Burst |
| `cross` | Holy rays | Consecration, Divine Storm, Holy Light |
| `poison` | Green drips | Envenom, Garrote — **also nature heals (bug)** |
| `skull` | Shadow swirl | Shadow Bolt, Death Coil, Chaos Bolt |

**Spawn:** `SpatialCombat._spawnBurst`, `_spawnRing`, `_spawnCone`, `_spawnSpark`, `_spawnSlash`; themed via `SpellVfx.spawnCast` / `spawnImpact` / `spawnBeam`.

**Paint:** `_TileRoomPainter` burst loop; non-inline kinds delegate to `_paintSpellBurst`.

### 2.2 Ground discs (`SpatialGroundFx` + `SpatialGroundFxKind`)

**Cap:** 6 (`_maxGroundFx`)

| Kind | Visual |
|------|--------|
| `disc` | Stroke only |
| `holy` | Spokes + inner ring |
| `frost` | Crystal wedges |
| `fire` | Flame ovals |
| `rain` | Drop lines |
| `shadow` | Dark swirl arc |
| `nature` | Leaf ovals |
| `steel` | Spinning arcs |

**Spawn:** `SpatialCombat._spawnGroundFx` from `_groundNova` and party heals when `def.vfx?.groundDisc` or `groundDiscLifeFor(id)` is set.

**Paint:** Ground loop when `showGround` (`vfxQuality.showGroundFx`). Comment in painter: *"Lite keeps these; Minimal hides them."*

### 2.3 Projectiles / bolts (`SpatialProjectile` + `SpellBoltStyle`)

**Cap:** 36 (`_maxProjectiles`)

**Styles:** `weapon`, `fire`, `frost`, `holy`, `arcane`, `shadow`, `nature`, `arrow`, `lightning`, `demon`, `poison`.

**Patterns:** `single`, `spread`, `arc`, `pierce` (`ProjectilePattern`).

**Resolution:** `SpatialCombat.boltStyleForAbility` — def `vfx?.boltStyle` → `def.boltStyle` → `_boltStyleForAbilityId` → keyword hash → `boltStyleForHero`.

**Trails:** Full only (`showProjectileTrails`); Lite/Minimal use short bright nub.

### 2.4 Floaters (`SpatialFloater` + `SpatialFloaterKind`)

**Cap:** 8 (trim by priority)

| Kind | Priority | Content |
|------|----------|---------|
| `combat` | 0 routine, 1 heal/ability, 2 crit/loot | Damage/heal numbers |
| `speech` | varies | CombatPresence barks |

**Lite:** paints floaters with `priority >= 2` only (crits, big heals, BLOCK, God Hand damage).  
**Minimal:** no floaters.

Routine white-hit floaters throttled (~28%). Ability-name floaters mostly suppressed (`_announceCast` burst-preferred).

### 2.5 Actor flash & cast ring (timers on `SpatialActor`)

| Timer | Painted as |
|-------|------------|
| `hitFlash` | Sprite scale/tint on hurt |
| `attackFlash` | Brief attack pop |
| `castFlash` | Caster tint |
| `castingTimer` / `castingDuration` | Cast progress arc (UI) |

These are **sim state**, not burst lists — they paint on Lite when auras/guide flags allow.

### 2.6 Auras (painter reads buff timers — no `SpatialAura` type)

Painted when `showAuras` (`vfxQuality.showActorAuras`):

- Ice block, absorb shield, combustion, pain suppression, fortitude
- Blade flurry, killing spree, power infusion
- Prayer of Mending orbs, inner fire, slice & dice, sprint
- Shield wall / shield block, last stand
- Generic `buffTimers['shield'|'buff']`
- Enemy: living bomb fuse, sunder, root, enrage

### 2.7 Boss telegraph

**UI-only:** red expanding stroke when enemy `fireCooldown < 0.45`. No dedicated sim type.

### 2.8 God Hand

**World fields:** `guideX/Y`, `guideTimer`, `pulseX/Y`, `pulseTimer`, `godHandRadius`, `godHandCooldown`.

**Style tint** from `metaDepth.godHandStyle`: BAL gold, FOCUS orange, WIDE blue.

**Spawn:** `SpatialCombat.godHand` — rings + burst when `vfxQuality != VfxQuality.minimal` (explicit comment: *"Smash must read even on Lite"*). Damage floaters also skip Minimal only.

**Paint:** Guide/pulse circles when `showGuide`; `_GodHandRingPainter` for CD ring (HUD chrome).

### 2.9 Flask heal FX

`SpatialCombat.spawnFlaskHealFx` — green heal rings on living heroes. **Skipped entirely when `reducedVfx`** (Lite + Minimal).

### 2.10 Stairs / door progress chrome

| Element | Minimal | Lite | Full |
|---------|---------|------|------|
| Stairs `GO` label | always | always | always |
| Stairs pulse ring | no | yes | yes |
| Open gate gold stroke | always | always | always |
| Exit clear ring/burst on floor complete | no | no | yes |

Painter comments: *"Open door always reads as progress (even Minimal VFX)"* and *"GO stays visible even on Minimal VFX"*.

### 2.11 Camera punch

`GameDirector.pulseCombatShake` — skipped when `vfxQuality == VfxQuality.minimal`.

### 2.12 Enemy VFX

No `AbilityVfxSpec` for enemies.

- `hitFlash` on damage
- `_tickEnemySpecials`: text floaters (`ENRAGE`, `HEX`, `CLEAVE`, `FORTIFY`, `PULSE`) + generic red `_spawnBurst` (not `SpellVfx`)
- Support heal floaters (`+N`)
- Boss size + wind-up telegraph (UI)

## Part 3 — Full / Lite / Minimal

### 3.1 `VfxQuality` flags (`lib/models/vfx_quality.dart`)

| Getter | Full | Lite | Minimal |
|--------|------|------|---------|
| `reduced` | false | true | true |
| `showBurstsAndFloaters` | true | false | false |
| `showPriorityFloaters` | true | true | false |
| `showActorAuras` | true | true | false |
| `showGroundFx` | true | true | false |
| `showGuideAndPulse` | true | true | false |
| `showProjectileTrails` | true | false | false |
| `showLootPulse` | true | false | false |

### 3.2 Shipped copy

| Source | Lite claim |
|--------|------------|
| `VfxQuality.settingsHint` | *"Crits & heals stay — routine floaters/bursts off"* (no mention of discs) |
| `game_guides.dart` | Full / Lite / Minimal named; Lite = crits/heals/BLOCK stay |
| What’s New **1.12.5** | *"Lite keeps ground discs (Consecration / Bladestorm) and auras — only Full shows floaters/bursts"* |

### 3.3 Spawn vs paint — P0 mismatch

**Painter:** Lite paints `groundFx` and auras (`showGround`, `showAuras` = true).

**Spawn:** Almost all ability VFX uses `if (!reducedVfx)`, and `reducedVfx => vfxQuality != full`. So **Lite never spawns**:

- `SpellVfx.spawnCast` / `spawnImpact`
- `_spawnGroundFx` inside `_groundNova` (Consecration, Bladestorm, Whirlwind, …)
- Self-buff rings, flask heal FX, routine burst/floater spam

**Exception:** God Hand uses `vfxQuality != minimal` — works on Lite.

**Offline:** `offline_sim.dart` forces `VfxQuality.minimal` during sim, restores player setting after — correct for catch-up.

**Reduced-mode cast pulse:** `_announceCast` spawns a tiny faded burst when `reducedVfx` so offline isn’t fully silent — not the same as ground discs.

### 3.4 Test gap

`test/spell_vfx_test.dart` asserts `VfxQuality.lite.showGroundFx == true` but **does not** integration-test that Consecration spawns `world.groundFx` on Lite. Flags-only coverage misses the spawn bug.

### 4.2 Runtime resolution (wider than def fields)

| Source | ~Abilities |
|--------|------------|
| Def `vfx` / `boltStyle` | 95 |
| `_boltStyleForAbilityId` only | 88 |
| Keyword / hero-spec fallback only | 88 |

Fallback chain:

```
def.vfx?.boltStyle ?? def.boltStyle
  → _boltStyleForAbilityId(id)
  → keyword scrape (id / name / shortLabel)
  → boltStyleForHero(class, spec)  // often weapon
```

Burst/ground shape:

```
SpellVfx._burstKindForId(id) ?? shape default ?? burstKindForStyle(style)
SpellVfx._groundKindForId(id) ?? groundKindForStyle(style)
```

### 4.3 `SpellVfx` AbilityId overrides

**`_burstKindForId` (~53 ids):** beam (Chain Lightning, Penance, …), rain (Hurricane, Volley, …), shards (Howling Blast, Ice Lance, …), flame (Fireball, Immolate, …), cross (Consecration, Holy Light, …), poison (Envenom, **Healing Wave, Riptide, Rejuvenation, Wrath**), skull (Shadow Bolt, Chaos Bolt, …), slash (Bladestorm, Whirlwind, …), cone (Shockwave).

**`_groundKindForId` (~27 ids):** holy, rain, fire, frost, shadow, nature, steel families (Consecration, Healing Rain, Explosive Trap, Shadowfury, Tranquility, Bladestorm, …).

### 4.4 `groundDiscLifeFor` (central disc durations)

Signature AOEs with default life seconds include: Consecration (6.0), Healing Rain / Tranquility (5.5), Bladestorm / Divine Storm (3.2), Whirlwind / Holy Nova (2.5), Shadowfury / Blast Wave (1.6), Fan of Knives (1.5), etc. See `SpatialCombat.groundDiscLifeFor` in `spatial_combat.dart`.

## Part 5 — Identity bugs & verdicts

### P0 — honesty / settings mismatch

| Issue | Detail | Files |
|-------|--------|-------|
| **Lite ground discs never spawn** | `_groundNova` wraps `_spawnGroundFx` in `if (!reducedVfx)`; Lite has `reducedVfx=true` | `ability_effects.dart`, `vfx_quality.dart` |
| **Copy overpromises** | What’s New 1.12.5 + painter comment vs spawn gate | `meta_systems.dart`, `spatial_dungeon_view.dart` |
| **Tests don’t catch spawn** | `spell_vfx_test` checks flags only | `test/spell_vfx_test.dart` |

**Suggested fix:** Use `vfxQuality != VfxQuality.minimal` (or a dedicated `spawnGroundFx`) for disc spawn paths; keep routine bursts behind `!reducedVfx`. Add integration test: cast Consecration on Lite → `world.groundFx.isNotEmpty`.

### P1 — wrong fantasy read

| Issue | Detail | Files |
|-------|--------|-------|
| **Nature heals = poison burst** | `burstKindForStyle(nature) => poison`; explicit poison on Wrath, Rejuvenation, Healing Wave, Riptide | `spell_vfx.dart` |
| **Chaos Bolt fire/skull split** | `boltStyle: fire` but `_burstKindForId` → skull | `class_ability.dart`, `spell_vfx.dart` |
| **Vendetta as nature** | Assassination amp reads green/nature | `class_ability.dart` / id-map |
| **Backstab / Hemorrhage shadow** | Combat Fan of Knives is weapon — intentional split, but Backstab shadow is soft | id-map |

### P2 — coverage / polish

| Issue | Detail |
|-------|--------|
| Thin hunter / Prot / Ret / Arcane / resto kits | Add `AbilityVfxSpec` + `castArgb` on signature combat rows |
| High-visibility fillers lack cast tint | Fireball, Frostbolt, Aimed, MS, CS, etc. |
| Enemy casts generic | Red disc only — no school-themed telegraphs |
| Flask FX silent on Lite | May be intentional; document or exempt like God Hand |
| No painter golden tests | `_paintSpellBurst` / `_paintGroundKind` untested visually |

## Part 6 — What already works

- **GO + open door** always visible on Minimal — no soft-lock on exit read.
- **God Hand smash** spawns on Lite (`vfxQuality != minimal`).
- **Cast ring, hit flash, boss telegraph** use actor/painter state — independent of burst spawn gates.
- **Offline catch-up** forces Minimal + strips VFX lists — performance-safe.
- **Spot tests** cover P1 themes, false-positives (Cheap Shot ≠ arrow, feral = weapon), signature `AbilityVfxSpec`, `groundDiscLifeFor`, burst/ground kind maps.
- **Caps** prevent VFX list blow-up (22 bursts, 6 ground, 36 projectiles, 8 floaters).
- **SpatialCombat single authority** — no second offline VFX fork.
