# SELL JUNK audit — 2026-08-03

## Verdict

SELL JUNK **does not** mean “sell all non-upgrades.” It intentionally **protects rare+** until the bag is nearly full, and treats **any piece better than an empty slot** as an upgrade. That matches the “sometimes it won’t sell junk” reports.

## Actual keep rules

| Rule | When | Keeps item? |
|------|------|-------------|
| In BiS plan (`planBiSAssignments`) | Always | Yes |
| Upgrade for any hero (`powerDelta > 0`) | Always | Yes |
| Rarity ≥ rare | Bag **&lt; 90%** full | Yes (**even if not upgrade**) |
| Best `powerScore` in that stash slot | Bag **≥ 90%** (unstick) | Only the top piece (+ soulbound) |

Code: [`_shouldKeepWhenSellingJunk`](lib/core/game_logic.dart) → [`autoSellJunk`](lib/core/game_logic.dart).

Settings copy is accurate but easy to miss: *commons / non-upgrade uncommons; when FULL also dumps non-BiS rares.*

## Why it feels wrong

1. **Rare junk never sells** while stash &lt; ~45/50 — most of the mid/late bag.
2. **Empty slots** → weak legal gear is `isUpgrade` forever (score vs empty = 0).
3. **Any hero** can claim a keep (spare caster cloth blocks sell while you care about tanks).
4. Pickup auto-sell (ilvl cap) **can** sell rares; bag SELL JUNK often won’t — inconsistent.

## Findings

- **P0** — Rare+ protected until unstick (≥90% bag).
- **P1** — Empty-slot auto-upgrade keep; UI “non-upgrade” mental model ≠ code.
- **P2** — Unstick uses `powerScore` not role/spec score; any-hero keep is broad.

## Suggested fix

1. Sell rare+ when not BiS/upgrade (same bar as uncommon), **or** add an Aggressive SELL JUNK mode.
2. Empty slot: keep only if BiS-planned or score ≥ minimum threshold.
3. Unstick: max `specEquipScore` across party, not raw `powerScore`.
