## Summary

Fury reads as **berserker dual-wield spam** (Bloodthirst / WW / Enrage / Death Wish) on the shared runner, but **`AbilityId.furyExecute` (“Rampage”) is falsely execute-gated** because `_isExecuteAbility` matches the substring `execute` in the enum name — so the signature dump only fires ≤25% HP. That is a must-fix P0 wiring bug. Numbers are mid-pack otherwise.
