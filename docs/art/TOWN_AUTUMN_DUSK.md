# Town target look: autumn dusk

Owner pick (2026-11-15): variant **B, "Skymning med hjältar"**.
Reference image: `docs/art/town_autumn_dusk_reference.jpg` (mood target only,
not shipped, not traced; every shipped pixel is generated by
`tool/generate_town_art.py` / `tool/town_life_art.py`).

## What the reference asks for

| Element | Target |
|---------|--------|
| Sky | Purple at the top, orange/red glow at the horizon, dark lumpy clouds |
| Trees | Orange, rust and red canopies; falling leaves |
| Buildings | Dark stone tower + half-timbered houses, warm lit windows |
| Square | Cobblestone with scattered leaves, not green lawn |
| Props | Jack-o-lanterns, pumpkins, baskets, central campfire |
| Light | Warm point lights (fire, lanterns, windows) against cool purple shade |
| Mist | Low, soft fog bands near the ground |
| Detail | 16-bit density: 1 px warm ink, clustered highlights, same as the heroes |

## Rules kept

- Layout, hit boxes, and name chips do not move (`TownSceneLayout`).
- `FilterQuality.none`, native pixel sizes. No FittedBox shrinking.
- Ambient motion (leaves, fire flicker) only when `townFolkMotionEnabled`.
- Free tools only (Python + PIL, Dart). Deterministic, no RNG.
